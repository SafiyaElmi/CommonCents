## About the Project

**CommonCents** is a web-based student marketplace developed for students at the Cape Peninsula University of Technology (CPUT).

The platform provides students with a space to buy and sell items within their university community. Users can browse available products, create their own listings, interact with other users and manage their marketplace activities.

The project was developed as part of a group development project, allowing us to apply our programming and database knowledge to a practical website.

## The Problem

Students often need affordable items but may find it difficult to locate other students selling the products they need.

There is a need for a convenient platform that brings student buyers and sellers together.

## Our Solution

CommonCents aims to provide a central online marketplace specifically for CPUT students.

Through the website, students can:
- Browse products listed by other students.
- Advertise and sell their own items.
- View product information and prices.
- Manage their shopping cart and orders.
- Interact with marketplace features such as notifications and reviews.

## Key Features

### User Accounts
- Register and sign in to the platform.
- Access personal account information.
- Manage account details.

### Product Listings
- Create and manage product listings.
- Add product names, descriptions, prices, conditions and images.
- Browse products available on the marketplace.
- View products according to their categories.

### Shopping Cart and Orders
- Add products to a shopping cart.
- View selected items.
- Continue through the ordering process.

### Notifications
- View notifications linked to account activity.
- Mark individual notifications as read.
- Mark all notifications as read.
- Delete individual notifications.

### Reviews and Ratings
- Submit ratings and written reviews on listings.
- View reviews submitted by users.
- Delete your own reviews.

## Getting Started

To run CommonCents on your local computer, you will need:

- [WAMP Server](https://www.wampserver.com/)
- A web browser
- The CommonCents project files
- The project's MySQL database SQL file, if included

### Installation Steps

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Move the project folder**

Place the downloaded project folder inside the WAMP `www` directory.

**3. Set up the database**

- Open phpMyAdmin through WAMP.
- Create the required database.
- Import the project's SQL file, if included.

**4. Configure the database connection**

Check the PHP database connection file and ensure the database name, username and password match your local MySQL setup.

**5. Start the project**

Make sure Apache and MySQL are running in WAMP.

Open your browser and navigate to:

```text
http://localhost/your-project-folder/
```

*Note: The exact database configuration and setup may depend on the files included in the repository.*

## Future Improvements

Although CommonCents provides the main features of a student marketplace, there are opportunities to improve the platform further.

- **Student Verification:** Introduce CPUT student email verification.
